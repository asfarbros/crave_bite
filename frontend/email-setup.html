Email Setup Guide

Get real confirmation emails working in 5 minutes!

Option 1: EmailJS (Recommended)

Step 1: Sign Up

Go to EmailJS.com and create a free account

Step 2: Add Email Service

Connect your Gmail account in the Email Services section

Step 3: Create Template

Create an email template for booking confirmations

Step 4: Get API Keys

Copy your Service ID, Template ID, and Public Key

Step 5: Update Code

Replace placeholders in booking.html with your actual keys

Step 2: Get Form ID

Copy your unique form ID (e.g., xayzqkqw)

Step 3: Update Code

Replace the form ID in booking.html with your actual ID
